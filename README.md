# Shauri Moyo SDA Church — Kanisa Platform

A full-stack church engagement and operations platform built with Next.js, Supabase, and Pesapal.

## What's inside
- 5 public pages: Home, About, Give, Request a Meeting, Resources
- Live Sabbath countdown
- M-Pesa + card giving via Pesapal
- Supabase database for donation records
- Role-based dashboards (coming in Sprint 1)
- Member database and attendance tracking (coming in Sprint 2)

## Setup instructions
See `PESAPAL_SETUP.md` for the full step-by-step guide to connect Supabase and Pesapal.

## Tech stack
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Payments:** Pesapal (M-Pesa + card)
- **Deployment:** Vercel
- **Fonts:** Fraunces + Work Sans (Google Fonts)
